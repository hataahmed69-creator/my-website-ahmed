# HUE — Coin Toss Simulation

HUE is an interactive browser simulation that demonstrates the Law of Large Numbers. Toss a coin once or in batches and watch the observed results change as the sample grows.

## Features

- Run individual or batch coin tosses.
- Adjust the number of tosses, coin bias, and simulation speed.
- Track heads, tails, percentages, total tosses, and the current streak.
- View live charts that show the results and their movement toward the expected probability.
- Reset the simulation at any time.

## Run locally

Open `index.html` in a modern browser. The page is self-contained and has no build step or package installation.

An internet connection is needed to load Chart.js and the Cairo and Bebas Neue fonts from their CDNs.
